# Donut Sniper (Fabric 1.21.11)

Build with no local setup:
1. Create a new GitHub repo and upload everything in this folder (including the hidden .github folder).
2. Open the Actions tab -> "build" -> wait for the green check.
3. Download the artifact "donutsniper-jar", unzip it, and use the jar WITHOUT "-sources" in the name.
4. Put it in .minecraft/mods with Fabric Loader + Fabric API for 1.21.11.
